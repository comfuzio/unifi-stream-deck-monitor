UniFi Monitor setup

Connect directly to your local UniFi console using a read-only Integration API key. Your UniFi account password is not needed. The key is stored in the operating system's credential store; it is not saved in Stream Deck action settings.

Permissions: the key should have only the read access needed to view sites and connected clients. The plugin makes HTTPS GET requests to your configured console. TLS certificate verification stays enabled. No telemetry or third-party analytics are included; the plugin does not send monitoring data to Comfuzio or any other service.

No administrator password should be needed. macOS may ask you once to allow Keychain access; if it asks on every launch, do not keep approving it—check the app's signing/Keychain access and report the issue.
